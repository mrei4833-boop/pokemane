ぽけマネ - iPhoneホーム画面対応Webアプリ

公開方法（GitHub Pages）
1. GitHubに無料アカウントを作成。
2. 新しいPublicリポジトリを作成（例: pokemane）。
3. このフォルダの中のファイル6個をリポジトリの一番上にアップロード。
4. Settings > Pages > Build and deployment > Deploy from a branch を選択し、main / (root) を指定してSave。
5. 数分後に表示される https://ユーザー名.github.io/pokemane/ をiPhoneのSafariで開く。
6. Safariの共有メニューから「ホーム画面に追加」を選択。

注意：データは端末のブラウザ内に保存されます。異なる端末には同期しません。Safariとホーム画面アプリでは保存領域が異なる場合があります。貯金タブからバックアップを保存してください。
実際の給与明細とは一致しない場合があります。深夜・残業割増、税金、社会保険料などは未対応です。
公開リポジトリに個人のシフト・支出データを書き込まないでください。データはアプリ実行時に端末内へ保存されます。
